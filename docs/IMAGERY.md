# 意象标注规范

标注或修改意象数据（`imagery`、`imagery_categories`、`imagery_motifs`、`imagery_occurrences`）与歌曲基调（`emotions`、`song_emotions`）之前先读本文件。规则的来由见第六节「为什么这样定」。

## 一、三个层次

一条标注回答「歌词里写的是什么东西」，分三层：

| 层   | 例         | 存在哪里                                    | 说明                               |
| ---- | ---------- | ------------------------------------------- | ---------------------------------- |
| 词   | 明月       | `imagery`                                   | 歌词里的原文写法，用于高亮         |
| 母题 | 月         | `imagery_categories`（第三级）              | 这个词指的东西，统计和推荐按它聚合 |
| 分类 | 自然 › 天象 | `imagery_categories`（第一、二级）          | 母题所属的门类与类别               |

- 一个母题只属于一个二级分类。分类由母题决定，标注时不单独选分类。
- `imagery_occurrences.category_id` 指向母题（第三级），不指向二级分类。
- 词能取哪些母题，记在 `imagery_motifs` 里：
  - `primary`：默认母题，每个词恰好一个。
  - `alternative`：多义词的其他候选。标注时按语境在 `primary` 与 `alternative` 中选一个。
  - `part`：并列词的其余组成。「风雨」的 `primary` 是风、`part` 是雨，标注时两条都写，时间标签相同。

后台怎么维护这些数据：

- **意象库**（`/admin/imagery`）：门类 › 类别 › 母题。门类与类别只读，只能在某个类别下新增母题，说明必填。点母题看登记在它下面的词；点词看它登记的母题（可设默认、加多义候选或并列组成、去掉没有标注的候选）和标在哪些歌里。
- **标注**（歌曲工作台「意象」一栏）：手动添加与预标注审核走同一个接口。词不单独新建或改名，标注时按歌词原文创建；改名会让它的标注全部对不上歌词。
- 标注时母题下拉框只列这个词登记的母题（默认母题打头），「其他母题…」展开全部。选了登记之外的，保存时登记为多义候选；新词以第一次选的母题为默认母题。
- 把一条标注改挂到别的母题后，若这个词在原母题下已没有任何标注、而原母题是它的默认母题，默认母题跟到新母题上，原母题的登记删掉。
- 母题一律按第三级判断（`level = 3`），标注、登记都只能挂在母题上。

## 二、分类体系

三个门类、十七个二级分类。新增二级分类要先讨论，母题可以按第四节的标准增减。

| 门类 | 二级分类 | 定义                                                             |
| ---- | -------- | ---------------------------------------------------------------- |
| 自然 | 天象     | 天空与气象，以及日月星辰、光影、火与烟等自然现象                 |
| 自然 | 时令     | 季节、节气、节日，以及晨昏昼夜等一日之中的时辰                   |
| 自然 | 山水     | 山、水、土石、原野等地貌，及其上的道路                           |
| 自然 | 草木     | 植物：花、树、草、竹、庄稼                                       |
| 自然 | 鸟兽     | 现实中的动物，含虫鱼；神兽归入神异                               |
| 人文 | 建筑     | 城、楼、亭、桥、寺塔、坟墓等建筑，以及门窗、檐、墙、阶等构件     |
| 人文 | 地域     | 有名有姓的地方，以及江湖、人间、天涯、故乡、边塞这类人文空间     |
| 人文 | 器物     | 人造物品：兵器、乐器、文房、衣饰、灯烛、舟车、日用；酒茶归饮食   |
| 人文 | 饮食     | 酒、茶、食物，以及酒器与酒肆                                     |
| 人文 | 人物     | 人的身份与角色：少年、故人、英雄、美人、过客                     |
| 人文 | 身体     | 身体部位与体貌：眉眼、容颜、发、泪、血、骨                       |
| 人文 | 艺文     | 诗词歌赋、书画、戏曲、史书、故事等文艺作品及其载体               |
| 人文 | 世事     | 人间的事件与活动：战争、宴饮、婚丧、科举、占卜、节俗             |
| 人文 | 神异     | 神佛鬼怪、神兽、仙境与冥界、法宝与玄学                           |
| 情志 | 情感     | 直接说出情绪的词：相思、离愁、悲愁、恨、孤独                     |
| 情志 | 心象     | 心里的东西：梦、誓、缘、记忆、愿、命运、魂魄、心                 |
| 情志 | 光阴     | 时间本身：岁月、刹那、千秋、往昔、青春、人生、轮回               |

容易放错的几处：

- 「心」几乎都指心绪，归心象，不归身体。
- 季节与时辰归时令；「岁月」「千年」这类时间本身归光阴。
- 「红尘」「人间」「江湖」「天涯」是人文空间，归地域，不归情感。
- 「风月」在库里几乎都指情事，整体归情感。

## 三、标注什么

**标。** 歌词正文里字面出现的、指一个东西或一种心象的词。

**不标。**

- 制作名单、标题行、文案与故事旁白。
- 成语与固定说法整体不当意象：风流、捕风、云泥、翻云覆雨手、电光石火。其中确实写到景物的（披星戴月）按并列词拆。
- 虚指的时间与形容：今日、很久、红色、模样。
- 只是字形碰巧相同的词：「红包」不是花，「木门」不是树，「风筝」不是气象。**分类看词义，不看首字。**

**词取多长。** 取歌词里完整的那个词：「残阳」标「残阳」，不再另标「阳」；「岁月」里的「月」不标。预标注会把被长词覆盖的短词默认取消勾选。

**只标歌词里写出来的词。** 标注的词必须在歌词里字面出现。写的是「踏雪」就标「雪」，不标「风雪」；只写了「举杯」就标「杯」，不标「酒」；「雪吹满鬓发」不标「白发」。意思上的关联交给母题，不靠把词挂到没有它的行上。

**时间标签。** 由系统按歌词算出，不手选：恰好是词在本曲字面出现的所有行，被同曲更长标注词覆盖的行除外（标了「岁月」，「岁月」里的「月」不再算「月」的出现）。行内空白不算，「地老 天荒」即「地老天荒」。歌词有时间轴时，后台拒绝保存歌词里没有的词。

**检查。** `pnpm imagery:check` 报告没有母题的词、挂错母题的标注、缺的并列组成和时间标签的出入；加 `--fix` 把时间标签改成词字面出现的行。发布歌曲时会按新歌词自动重算时间标签，歌词里找不到的词在后台提示；绕过后台改了正式表的歌词，要手动跑一次。歌词里找不到该词的标注只列出，要人决定删掉还是改标实际写的词。

## 四、母题的粒度

- **修饰并入主体。** 落花、繁花、山花 → 花；孤舟、轻舟、扁舟 → 舟；明月、月光、月色 → 月。修饰带来的意味（落、孤、残）交给情感轴，不另立母题。
- **有传统意蕴的品种单列。** 梅、柳、桃、杏、梨、海棠、牡丹、荷、菊、桂、梧桐、松、竹、枫、芦苇等单列；其余并入花、树、草。
- **保留标准。** 一个母题至少满足一条：
  1. 常用：出现在 3 首歌以上。
  2. 有并入后会丢失的传统寓意：红豆、彼岸花、青鸟、鹊、飞蛾、丁香、芭蕉、朝堂、科举。
- **地名。** 长安、江南、洛阳、金陵单列，其余并入「地名」。
- **现代器物。** 电话、飞机、卡带等并入「现代器物」，用来区分古风与现代题材。

新词入库时先找已有母题；确实没有合适的，按上面的标准新建，并在 `imagery_categories.description` 写一句它指什么。意象库的「整理」列出没有标注的母题（只看第三级），勾选后删除；登记了它的词随之解除登记，以它为默认母题的词改用其余候选里标注最多的。

## 六、为什么这样定

2026-10 整理前的问题：

- 第三级分类有 341 个，其中 187 个与意象词同名、203 个只挂了不到 3 条标注，又混着「气象」「星相」这样上百条的大桶。
- 分类挂在每条标注上且可自由选择，同一个词在不同歌里被分进不同分类（「天地」落在 10 个分类）。
- 大量词按首字归类：「红包」「红楼」归花，「木门」「旋转木马」归树，「风筝」「风铃」归气象。
- 词的粒度不一：2,745 个词中 1,840 个只出现在一首歌里，「月」「明月」「月光」「月色」互不相干。

整理后：2,745 个词归到 312 个母题，统计和推荐按母题聚合。语境仍由标注者判断，但只在该词登记的候选里选。

## 七、基调

基调标在**歌**上，不标在单条意象标注上：情绪在句子和全曲里，「剑」「月」本身没有情绪。某个母题常出现在什么基调的歌里，由歌的基调与标注关联算出。

- 存在 `song_emotions`，词表在 `emotions`。后台在歌曲工作区的「基调」一栏标。
- 每首歌 1 个**主基调**，另可加 0–2 个**副基调**（《倾尽天下》= 悲怆 + 执守）。
- 读完全曲判断，对白、旁白也算，不只看副歌或歌名。
- **怅惘只在整首都在回望时标**：歌里的「现在」只是回忆的引子（《烬》《陈年卷》）。只有几句提到往事的，往事是思念、执守等的底色，不标怅惘。
- 「悲壮」不单设，用「豪迈 + 悲怆」表达。

词表 11 个，按情绪的冷暖（明 / 暗）与强弱（扬 / 抑）归位：

| 象限 | 基调 | 指什么 |
| ---- | ---- | ------ |
| 暗·抑 | 思念 | 念人、怀乡、等人归来 |
| 暗·抑 | 离愁 | 分别当下或将要分别的痛 |
| 暗·抑 | 孤寂 | 独自一人，无人懂、无人知 |
| 暗·抑 | 怅惘 | 若有所失，往事不可追 |
| 暗·抑 | 苍凉 | 兴亡与时间面前人的渺小；怀古 |

| 暗·扬 | 悲怆 | 死别、国破、宿命这类强烈的痛 |
| 暗·扬 | 执守 | 明知无望仍不放手：痴情、守诺、守城 |

| 明·扬 | 豪迈 | 快意、壮志、江湖气 |
| 明·扬 | 欢快 | 喜庆、诙谐、轻松热闹 |

| 明·抑 | 洒脱 | 看开、闲适、超然物外 |
| 明·抑 | 温柔 | 眷恋、甜蜜、暖意与珍惜 |

增删基调要先讨论：词表一变，已标的歌都要重看。
